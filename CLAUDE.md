**SECOND BUG FOUND AND FIXED (Jul 2026, deployment-readiness pass): sub-contractor pricing had the markup direction backwards.** `add_cost_groups_v2()`'s sub branch was dividing `sub_scope_price` by `SUB_MARKUP` (1.45) to compute "cost" — but the prompt (STEP 3B) explicitly tells Claude that `sub_scope_price` IS already OCC's real cost from the sub, before markup. So the code had it backwards: it was treating Claude's cost figure as if it were the already-marked-up client price, which would have billed the client exactly what OCC pays the sub — zero margin — on every single subcontractor line item (electrical, major HVAC/plumbing, crawlspace), while writing a fabricated, artificially-low "cost" into JobTread's own records. Fixed to multiply UP (`sub_price = sub_cost * SUB_MARKUP`) instead of dividing down.
